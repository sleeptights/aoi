## changelog

- **friends + crate** — add friends from the online list; shared crate sits above peers
- **multi accounts** — keep several SoundCloud logins and switch on the account screen
- **invite with track** — room invites carry what you’re hearing (and a seek hint)
- **notif chime + duck** — soft tone, music dips briefly; toggle in settings
- **quiet likes** — no spinning retry UI; success/fail lands in notifications
- **smarter crossfade** — longer overlap when the next artist matches
- **sleep by tracks / dawn queue** — stop after N tracks; optional morning auto-start hour
- **deep work · quiet hours · candle** — mute presence, slower night polling, fade UI brightness
- **settings backup** — atomic writes + one-click backup file
- **queue persistence** — last playback context survives a crashy quit
- **shuffle cooldown** — avoid three same-artist tracks in a row
- **HLS quality** — auto / sq / hq
- **visual** — quiet chrome, desaturated library until first play, rain on pause, buffer edge glow, black lift for OLED
- **media:// allowlist** — only app data + your music folder
